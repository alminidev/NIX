# QUALITY BAR

Um projeto só pode ser considerado finalizado quando atingir padrão profissional em cinco dimensões. Use isto no comando `/audit` para pontuar de 0 a 10 cada uma.

## 01 — VISUAL
- Identidade visual clara
- Tipografia com contraste e personalidade
- Composição intencional (não aleatória)
- Espaçamento consistente
- Hierarquia forte
- Imagens de qualidade, com crop e posição focal pensados
- Detalhes refinados (não só "funcional")

## 02 — UX
- Usuário entende a proposta em até 5 segundos
- Usuário sabe o próximo passo em qualquer ponto da página
- Informações importantes são fáceis de encontrar
- Navegação sem fricção
- Cada seção tem função clara — se não tiver, deve ser removida

## 03 — ENGINEERING
- Código limpo, modular, sustentável
- Responsivo de verdade (não só "não quebra")
- Acessível (contraste, semântica, navegação por teclado)
- Semanticamente correto (HTML correto, não `<div>` para tudo)

## 04 — PERFORMANCE
- Sem JavaScript desnecessário
- Sem imagens pesadas sem otimização
- Sem animações excessivas
- Sem dependências desnecessárias

## 05 — PERCEPÇÃO (o teste decisivo)

Faça a pergunta: **"Se este projeto fosse apresentado como trabalho de uma agência, eu acreditaria?"**

Se a resposta for não: **não entregar. Revisar.**

## Checklist rápido de entrega ("anti-AI checklist")

- [ ] O hero/abertura é memorável?
- [ ] A proposta é compreendida em 5 segundos?
- [ ] A tipografia tem personalidade?
- [ ] Existe hierarquia clara?
- [ ] Existe espaço negativo suficiente?
- [ ] As seções têm ritmo?
- [ ] Existe alguma seção desnecessária?
- [ ] Parece um template?
- [ ] Tem cards demais? Bordas arredondadas demais? Gradientes sem função?
- [ ] As imagens são realmente boas?
- [ ] O mobile foi projetado, não só encolhido?
- [ ] As animações têm propósito?
- [ ] O CTA está claro?
- [ ] O projeto transmite confiança?
- [ ] Parece feito por uma agência?

Se a resposta for "não" para alguma pergunta importante, ainda não entregue.
