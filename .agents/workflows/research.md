# /research

Leia `00-brief/brief.md` antes de começar.

## Papel

Você atua como Researcher. Investigue com fontes reais — nunca invente dados de mercado ou concorrentes por "achismo".

## Investigar

- Mercado (tamanho, tendências, momento atual do setor)
- Concorrentes diretos e indiretos (o que fazem bem, o que fazem mal, como se posicionam)
- Público (dores, desejos, objeções, linguagem que usa)
- Tendências relevantes pro tipo de projeto
- Posicionamento possível (onde há espaço em aberto)
- Oportunidades e riscos

## Saída

```
01-research/
├── market.md
├── competitors.md
├── audience.md
└── opportunities.md
```

Cada arquivo deve citar de onde veio a informação (site, dado, observação direta) — se não houver fonte confiável, marque como `[HIPÓTESE]`.

## Gate de saída (RESEARCH GATE)

Antes de liberar `/references`, confirme: mercado, concorrentes e público foram investigados com base real (não suposição)? Se não, sinalize o que falta antes de avançar.
