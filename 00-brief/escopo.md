# Escopo do Projeto — NIX

## Incluso
- Número de páginas/seções: 1 página (one-page responsiva com 6 seções: Cabeçalho fixo, Hero, Vitrine de 5 produtos, Diferenciais, FAQ/Como funciona, Rodapé)
- Rodadas de revisão inclusas (via /revise): 1
- Responsivo (mobile + desktop): Sim (mobile-first)
- Formulário de contato: Não (links diretos no rodapé e checkout externo)
- Outros itens combinados:
  - Desenvolvimento 100% front-end em Vanilla (HTML5, CSS3, JS)
  - Arquivo centralizado de dados dos produtos (`produtos.js` ou `produtos.json`) com renderização dinâmica
  - Atributos semânticos e identificadores (`data-sku`, `data-id`) nos cards
  - URL centralizada para redirecionamento do checkout/carrinho (InfinitePay)
  - README didático de entrega para integração com outro programador

## Não incluso
- Desenvolvimento de backend ou banco de dados
- Carrinho de compras dinâmico no front-end
- Processamento de pagamento interno
- Cálculo de frete ou cotação de transportadora no front-end
- Sistema de login, cadastro ou autenticação de usuários
- Integração de APIs com credenciais, tokens ou chaves secretas no front-end
- Criação e tratamento de fotografias ou renderização 3D dos produtos
- Redação publicitária completa dos 5 produtos (conteúdo deve ser fornecido pelo cliente)
- Páginas adicionais ou blog
- Hospedagem e manutenção mensal
