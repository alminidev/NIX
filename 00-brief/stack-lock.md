# Stack Lock — NIX

## Permitido (única lista válida)
- HTML5 semântico
- CSS3 puro (Vanilla CSS com variáveis `:root`, Flexbox, CSS Grid)
- JavaScript puro / Vanilla ES6+ (sem transpiladores)
- Arquivo de dados estático (`produtos.js` ou `produtos.json`) para renderização dos cards
- Fontes web carregadas diretamente (ex: Google Fonts Open Sans)

## Proibido (explícito — qualquer coisa fora da lista "Permitido" está implicitamente aqui também)
- Frameworks JavaScript (React, Next.js, Vue, Angular, Svelte, etc.)
- Frameworks ou utilitários CSS (Tailwind CSS, Bootstrap, Bulma, Sass/SCSS compilado externamente)
- Build tools, empacotadores ou bundlers (Vite, Webpack, Rollup, Parcel, esbuild)
- Dependências gerenciadas via `npm`, `yarn`, `pnpm` ou `package.json`
- Armazenamento de chaves de API, secrets ou tokens de qualquer natureza no front-end
- Lógica de backend, banco de dados ou rotas dinâmicas
